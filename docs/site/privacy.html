Privacy policy

For the iOS app built from this repository. Last updated 2026-09-17 (draft pending the owner's approval).

The short version

The app collects no data about you. There is no account, no analytics, no crash reporting, no advertising, no tracking and no third-party code of any kind in it.

What stays on your device

Favourites are stored on your device only. They are never sent anywhere, never synced, and are removed when you delete the app.

The one network request

When you open the app, and when you pull to refresh, the app requests one file: the public dataset at chelseakr.github.io/queer-tv-guide/snapshot.v1.json. The request carries no account, no cookie and no identifier created by the app. Like every web request, it reveals your IP address and a standard User-Agent (the app's name and version and your iOS version) to the server.

That file is hosted on GitHub Pages. GitHub states: "When a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes" (GitHub Pages documentation). That log is GitHub's, governed by the GitHub Privacy Statement. The app's developer does not receive it and cannot see it.

Links you open

Where-to-watch links and links to LezWatch.TV and TVmaze open outside the app, in Safari or in the linked service's app. What those sites collect is governed by their own privacy policies.

Children

The app collects no data from anyone, including children.
