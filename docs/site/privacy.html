Queer Frame privacy policy

Queer Frame for iPhone. Last updated 2026-09-18.

The short version

Queer Frame collects nothing about you. There is no account, no analytics, no crash reporting, no advertising, no tracking and no third-party code of any kind in the app.

What stays on your device

Favourites are stored on your device only. The app never sends them anywhere and never syncs them. Like other app data, they are included in your own iCloud or computer backup of the device, and they are removed when you delete the app.

You can also save them to a backup file yourself: on the Favourites screen, tap the … menu, then Export favourites. That file lists only which shows and characters you favourited and when. It goes wherever you send it from the share sheet (Files, AirDrop, or anywhere else you choose), and never to the developer. Import favourites reads a backup file you pick, on this device or another.

The one network request, and who serves it

When you open the app, and when you pull to refresh, the app requests one file: the public dataset at chelseakr.github.io/queer-tv-guide/snapshot.v1.json. The request carries no account, no cookie and no identifier created by the app.

That file is served by GitHub, through GitHub Pages. Like any web server, GitHub sees the IP address of every request, together with a standard User-Agent (the app's name and version and your iOS version). GitHub states: "When a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes" (GitHub Pages documentation). That log belongs to GitHub and is governed by the GitHub Privacy Statement. The developer of Queer Frame does not receive it and cannot see it.

Links you open

Where-to-watch links and links to LezWatch.TV and TVmaze open outside the app, in Safari or in the linked service's app. What those sites collect is governed by their own privacy policies.

Children

Queer Frame collects no data from anyone, including children.
