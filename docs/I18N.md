# i18n status: Applies — deferred to the first release with a second UI language (none is planned for 1.0)

Reason: the standard applies. The app shows natural-language text and
locale-formatted dates to people other than the developer, so the N/A
exemption in INTERNATIONALIZATION-STANDARD §1 (no human-facing output,
English only, no localized values) is not available. It is deferred, not
waived. The app is English-only by design: it is not a civic or public-service
product and owes no language by law, and its source data (LezWatch.TV's
descriptions and taxonomy, TVmaze's episode titles) is English. A translated UI
over untranslated data would be half a product.

Tracking issue: #23.

## What is true today

- **UI strings.** SwiftUI `Text("…")` literals are `LocalizedStringKey`s and
  `SWIFT_EMIT_LOC_STRINGS = YES` is set (`ios/Config/Shared.xcconfig`), so the
  strings can be extracted. There is no String Catalog (`Localizable.xcstrings`)
  and no second language. The project's development region is `en`.
- **Strings built in code.** GuideCore's `Presentation` assembles sentences
  with plain Swift interpolation (for example the "does she die" answers).
  These are not localizable as written.
- **Dates.** Shown through `DateFormatter` with `dateStyle`/`timeStyle`, so
  they follow the user's locale. Episode days are formatted in UTC
  (`Presentation.dayFormatter`), so a date does not shift a day with the
  viewer's time zone.
- **HTML.** `docs/site/privacy.html` declares `lang="en"`. The Pages status
  page is generated in `snapshot.yml` (#12).
- **Search** folds case, diacritics and width without a locale, so "Élite"
  matches "elite".

## Entry point if this changes

1. Add `ios/QueerTVGuide/Localizable.xcstrings`. Xcode fills it from the
   extracted `Text` literals.
2. Move every sentence GuideCore builds to `String(localized:)` with
   placeholders, and give plural cases (counts of characters, deaths, seasons)
   plural variations in the catalog, not English-only interpolation.
3. The INTERNATIONALIZATION-STANDARD §4 gates then apply: key parity,
   placeholder parity, plural categories, BCP 47 tags, a pseudolocale overflow
   check at accessibility text sizes.
4. Say in the listing that the show and character data stays in English.
